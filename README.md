# ProductFlow 🚀

Robot team that analyzes business ideas!

## How to Run

1. Make sure Node.js is installed
2. Go to the productflow folder
3. Run: `npm start`

## Folder Structure

- `robots/` - All the robot files
- `brain/` - Memory and learning
- `leader/` - Team leader
- `data/` - Where memories are saved

## The Robots

- Scout Robot - Analyzes market demand
- Detective Robot - Checks competitors
- People Robot - Finds users
- Money Robot - Calculates profit
- Feature Robot - Lists features
- Plan Robot - Creates roadmap
- Priority Robot - Prioritizes features

## Try It!

Edit `run.js` and change the product idea to whatever you want!
